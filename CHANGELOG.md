# Changelog

## 1.0.0

First release.

- One device per computer: timer running, minutes left, locked, connected.
- Flow triggers for a timer starting, time being added, a timer ending, the computer being locked and unlocked, and coming online or going offline.
- Flow conditions for the same, and actions to start a timer (for minutes, or until a time), add time, end the time now, and cancel.
- Pairing with an address and a key, and repair for a key that stopped working.
- English and Swedish.
